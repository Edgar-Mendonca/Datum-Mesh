# Datum Mesh 0.1: plan

Written 2026-10-28, day 1, from the hub brief (`Edgar-Mendonca/Datum/briefs/DATUM-MESH.md`). Every decision was made with the user in the hub (session 13), so this plan has no open questions: it records scope, the day plan and the risks, then we build.

## 1. Scope

Datum Mesh 0.1 is finite-element analysis in **2D**, with its own solver in Rust:

- **Frames and trusses**: nodes and members on a canvas; 2D Euler–Bernoulli beams and truss bars; sections from a library or your own A, I, depth; pinned, roller, fixed and spring supports; point forces and moments, uniform and linearly varying member loads, self-weight. Results: deflected shape, axial, shear and moment diagrams, reactions, stresses and utilisation.
- **Plane solids**: rectangles, circles and polygons (with arcs and holes); plane stress (with thickness), plane strain and steady heat conduction on the same mesh; constrained Delaunay triangles with quality refinement, 6-node triangles by default (3-node as an option); edge and point supports and loads, gravity; temperature, flux and convection. Results: displacement, von Mises, principal and component stresses, safety factor, temperature and flux; contours, deformed shape, probe, min/max, reactions against applied loads (the equilibrium check).
- **Materials** copied from Datum Atlas with their sources (Poisson's ratio added from our own typical values: Atlas has none).
- **Report** printed to PDF, and the **verification report** generated by the test suite at build time.

Not in 0.1: 3D, nonlinear, CFD, DXF import (0.2), modal and buckling (0.2). See the brief §8.

## 2. How it is built

- `crates/core` (pure Rust, unit-tested): `model` (the `.dmesh` document, versioned JSON with repair of damaged files), `doc` (edits as operations with snapshot undo, as in Plan and Sim), `mesh` (spade CDT + our refinement → T3/T6), `elements` (beam, truss, T3/T6 plane and heat), `solve` (triplets → CSC, supports by elimination, sparse Cholesky from faer), `post` (recovery, averaging, von Mises, principals, diagrams, reactions), `bench` (the benchmarks as data and tests), `hardening`.
- `src-tauri`: the shell from Datum Sim (itself Plan's), without Python: commands, files, options, recovery, recent files, the updater with `REPO = "Edgar-Mendonca/Datum-Mesh"`, a solve thread with progress.
- `ui`: the family window (ribbon Home · Geometry · Mesh · Loads · Solve · Results · View · Help, contextual Format), the canvas (pan, zoom, snap, rulers; SVG for geometry, Canvas 2D for contours), model tree, inspector, legend, `?` cards, Options, Print.
- Model units are SI base units (m, N, Pa, K) in the file; the window shows mm, kN, MPa (SI) or in, kip, ksi (US).

## 4. Risks

| Risk | What we do |
| --- | --- |
| Mesh quality on curved holes and fillets (benchmarks 4–6 depend on it) | Arcs split by the local size before triangulation; Ruppert-style refinement with a minimum angle; convergence studies in the tests show the error falling |
| Sparse Cholesky speed and licence | faer (MIT); fall back to a banded solver with reverse Cuthill–McKee ordering if faer's API or size is a problem |
| Contours slow on 50 000-node meshes in the WebView | Canvas 2D triangles with per-band fill, drawn from a typed array; the engine sends results once, the window only redraws |
| Units mistakes | One conversion table in the window (`units.ts`), SI base units everywhere in the engine and the file; every benchmark checked in SI |
| A week is short | Engine first with tests every day; the UI reuses Sim's and Plan's components; planned tools appear dimmed with their release |
